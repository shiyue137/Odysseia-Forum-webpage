# 自定义标签正式接入

## 范围

- 在 `codex/tag-system` 保留并复用 DEV 标签池草稿。
- 独立 `pnpm dev:tag-test`，本地 3001 端口连接测试后端 10810；普通 dev 和生产配置不变。
- `/tags` 标签池与原使用统计分开视图；BOT 管理员维护实体、别名和关系。
- 帖子详情是管理、提议、审核和投票入口；居中原生 dialog 复用标签池，支持多选。
- 帖子列表显示紧凑自定义标签，点击按内部字符串 ID 搜索。
- 同步测试端 OpenAPI，兼容可空 thread 的标签审核通知。

## 数据边界

标签池分页搜索由服务端执行。关系为 DAG，不自动添加上级或扩大搜索。
作者完整替换携带原 version；冲突保留草稿，重新读取后显式确认。
普通用户逐标签提议，逐项报告失败，不宣称批量原子性。
BOT 管理员与管理组分别判断，权限服务失败不得解释为无权限。
默认环境不开启未上生产的接口；不部署 Cloudflare，不修改后端、不执行真实业务写入验收。
本次聚焦帖子，书单治理 UI 不在范围内；新通知必须安全显示书单目标。

## 验证

主要风险：ID 精度、分页查询、并发覆盖、部分提交失败、内外弹层 Escape。
使用聚焦测试覆盖可执行逻辑；生成类型后检查跨模块调用；入口和环境变化运行构建。
不使用生产凭证向测试后端写入。登录后真实授权与视觉验收由用户执行。

## 本地测试

运行 `pnpm dev:tag-test`，访问 `http://127.0.0.1:3001/tags`。
`.env.tag-test` 已纳入版本控制，不包含凭证。普通 `pnpm dev` 仍连接原后端。
如 3001 被其他进程占用会明确退出，不自动占用未知端口。

测试模式使用独立 localStorage。Cookie 不按端口隔离，因此测试代理不转发 Cookie，也不接收 Set-Cookie；
登录后使用该 origin 自己的 Bearer token。不要把生产 token 复制进测试环境。
当前测试后端是 HTTP，仅用于本次受控本地测试，不是可公开部署的安全方案。

点击登录会进入测试后端 `/v1/auth/login-dev`。
本地后端源码中的开发认证完成页支持手动填写前端地址；在那里填写
`http://127.0.0.1:3001/tags`。

### 当前认证阻塞

2026-09-14 匿名读取两套 `/v1/auth/login-dev` 的 302 Location：

| 后端 | OAuth client_id | redirect_uri |
| --- | --- | --- |
| 测试 `23.238.110.155:10810` | `1403356025540579519` | `https://forum.shimmerday.top/v1/auth/callback-dev` |
| 主后端 `forum.shimmerday.top` | `1534822106771226745` | `https://forum.shimmerday.top/v1/auth/callback-dev` |

实际运行前端的 `VITE_BACKEND_URL` 已正确指向测试端，Bot 的 client_id 也与主后端不同，
但测试 OAuth 回调错误地回到主后端。需测试后端调整 `auth.redirect_uri`，
并与测试 Discord 应用登记的回调地址一致；前端不能只重写 authorize URL，
因为后端换取 token 也使用相同认证配置。尚未使用账号尝试授权或提交真实业务写入。

`pnpm gen:api:tag-test` 从测试端重新生成契约，失败不回退到其他后端。
此分支暂时不要运行面向主后端的 `pnpm gen:api`，主端尚未包含新增类型。
正式开放功能时再确认主后端契约并配置 `VITE_CUSTOM_TAGS_ENABLED=true`。

## 实际结果与限制

- 2026-09-14：5 个聚焦测试文件、34 项测试通过，覆盖版本冲突、逐项失败、Escape、
  字符串 ID、URL 往返、搜索请求、书单重复参数和空 thread 审核通知。
- 生产构建通过，新增组件定向 ESLint 通过，Diff 空白检查通过。
- 实际配置探针确认普通后端不变、测试代理 Cookie 隔离生效；
  测试 `/tags` 返回 200，匿名分类和身份接口返回 401。
- 尝试绑定 `127.0.0.2` 被本机拒绝，最终采用原回环地址 + 独立端口 + 代理 Cookie 隔离。
- 仓库同时跟踪 Vite TS 源码与生成 JS，测试命令显式指定 TS，生成 JS 已同步。
- 为避免搜索切换到书单时静默丢失 ID 条件，同步接入书单查询参数；未扩展书单治理 UI。
- 关系接口只有 ID，池按页加载；未加载关系节点显示 ID。申请接口也只有 tag_id，
  申请列表显示 ID，不按名称猜测、不自动扫描全库。后端补充按 ID 批量读取或申请标签快照后可改善。
- 管理关系支持已加载候选及目标 ID；目前没有独立的全库关系选择弹层。
- 未执行带真实登录身份的远端写操作；测试端 OAuth 回调配置阻塞真实登录验收。
  未执行真实浏览器视觉验收。需回调修复后人工核对手机布局、焦点及登录权限。
- 已有 React Router、SWC 和 Browserslist 提示未在本次范围内升级依赖。
