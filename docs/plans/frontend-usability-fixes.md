# 前端交互修复

Status: complete

目标：关注下拉框使用现有主题；作者作品每页 48 条显式分页；搜索排序行提供默认排序保存；标签图标显示未读与离线状态。

已确认事实与决策：复用 Select、AnimatedPagination、服务端 sort_method 和现有动态图标。排序保存保留其他偏好，只保存排序字段；当前排序与默认排序操作独立。作者页页码进入 URL，筛选与排序变更重置页码。图标复用顶栏未读状态，浏览器离线时灰度化。

非目标：后端、依赖、全站主题、搜索分页策略、默认升降序。

工作包与文件边界：MePage 两个关注分区；authors 查询与键、UserProfilePage；搜索排序组件、SearchPage 与偏好映射；DynamicFavicon、RootLayout、TopBar。主 Agent 实施及验收。

完成条件：三处下拉可键盘使用；作品第二页 offset=48，缓存区分页；快捷保存不丢频道/作者等偏好；图标状态切换不会被过期图片加载覆盖。

验证预算：对应组件/hook 定向测试，跨模块 Props 及查询参数使用类型检查；不运行完整测试或 build。主题和图标观感由用户人工验收。

停止条件：出现新增依赖、后端契约变更或范围扩大时上报。

开放问题：无阻塞问题。

最终结果：四项均已实施。三处原生下拉已替换；作者作品查询增加 URL 页码、offset 和分页缓存键，空页提供返回入口；默认排序保存保留除 user_id 外的现有偏好字段，并将当前排序显式写入 URL 避免被新默认覆盖；图标在 TopBar 消费现有合并未读状态，支持离线灰度、红点、表情延迟恢复和过期加载取消。

实际边界补充：共享 Select 增加可用高度与滚动，避免频道列表超出窗口；TestPage 的排序预览与生产复用 SearchSortMenu，只更新预览本地状态。未新增路由、依赖、后端修改或全局状态。

验证：5 个定向 Vitest 文件共 14 项通过，覆盖排序保存保留字段与失败反馈、独立操作及 Escape、作者分页请求与缓存、动态图标离线/未读/定时恢复/加载竞争，以及原有 Select 键盘操作。运行命令使用 NODE_OPTIONS=--no-experimental-webstorage，解决本机 Node 26 原生 Web Storage 与 jsdom 的环境冲突；首次未加参数的原有清空筛选用例因 localStorage 不可用失败。新增测试的 ES2020 类型兼容问题已修复，pnpm typecheck 通过；7 个相关 UI 文件的定向 stylelint 通过。

未验证与剩余风险：未连接真实后端进行保存或翻页验收，未启动浏览器做客观诊断或视觉验收。系统浅/深模式、窄屏面板和实际标签图标观感由用户确认。离线只表示浏览器报告断网，不等同于后端可达性；默认排序不保存正/倒序。
