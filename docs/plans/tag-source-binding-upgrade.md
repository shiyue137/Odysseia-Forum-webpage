## 统一实体规则

用户补充确认旧原生标签归一到标准标签实体，不能继续限制其别名和上下级。
前端移除原生独立分类与 source 导致的实体编辑限制；未分类实体仍可单独保存别名和关系，
仅提交真正变更的基本字段，不伪造 source=custom。
绑定治理与实体来源无关，DC 同步仍只读，本地绑定保留身份权限和后端校验。
